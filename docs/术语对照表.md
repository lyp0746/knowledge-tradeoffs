# 术语对照表：同一个词在九本书里指什么

> 系列写作跨了六年，术语在演化。这张表只做一件事：**指出同一个词在不同书里的所指差异**，避免把 A 书的定义套到 B 书上。

| 术语 | 首次系统定义 | 后续演化 | 引用时的建议 |
|---|---|---|---|
| 区分 | 《区分的语法》第 11 章：把对象分成可分辨的类 | 在其余书中作为“划线”的通俗说法 | 引严格定义时指《区分》；通俗语境可用“划线” |
| 容量 | 《遗忘的边界》第 5 章：有效容量 C_eff | 《选择的代价》中作为 C（完备）的资源前提 | 引“容量”时说明是信息容量还是注意力预算 |
| 时间错配 τ | 《错位的时间》第 3 章：T_min / T_available | 《选择的代价》中作为三角的时间见证 | τ 只作序数比较；不要跨书引用其数值 |
| 三角（C-A-T） | 《选择的代价》第 2 章 | 《诠释的权衡》中作为史学的让出结构 | 引三角时标“框架（C 级）”，不要当定理 |
| 置信度 | 《诠释的权衡》第 2 章：四层分配 | 通俗读本中简化为“这句话有多可信” | 引四层时说明层级，不要只说“置信度” |
| 临界 | 《涌现的临界》第 1–3 章：序参量 + 慢化 + 宏观有效 | 通俗读本中作为第六个核心 | 严格/削弱/隐喻三级必须标明 |
| 框架 | 《诠释的权衡》表 0.13 区分四种含义 | 系列级文档《框架的四级》给出四级 | 引“框架”前先确认是第几级 |
| 优雅降级 | 《错位的时间》第 22 章 | 《选择的代价》第 18 章扩展为制度预案 | 指“提前排序”，不是“放弃” |

**一条纪律：** 跨书引用时，**以首次系统定义为准**；后续书中的用法若不同，视为“扩展”，而不是“同义”。

## 演化逻辑：是精化、修正，还是替换？

术语变化不等于前后矛盾，但也不等于同一件事。这张表把每次变化归类，读者可据此判断“该用哪一版”。

| 概念 | 演化类型 | 说明 |
|---|---|---|
| 区分 | 精化 | 严格定义（《区分》）→ 通俗说法“划线”（读本），所指未变 |
| 容量 | 精化 | 从“有效容量”到“注意力/信息预算”，度量对象不变，口径更具体 |
| 时间错配 τ | 精化 | 从“比值”到“序数诊断”：数值仍在，但只用于排序，不再当作预言 |
| 三角（C-A-T） | **修正** | 早期试图形式化为不等式（失败，见《诠释》附录 J）→ 改为“价目表 + 反例库” |
| 置信度 | 精化 | 从“一个数”到“四层分配”，增加了层级，未推翻原定义 |
| 临界 | 精化 | 从隐喻 → 操作定义 + 三标记 + 校准实验 |
| 框架 | 修正 | 从“一个框架”到“四级强度”（概念工具集/坐标/模板/生成模型） |
| 优雅降级 | 扩展 | 从个人预案扩展到制度预案，定义未变 |

**读法：** 标“精化”的，用最新版即可；标“修正”的，**旧版说法已作废**（三角的形式化、框架的单一定义）；标“扩展”的，两者可并存。
