# 修订说明

## 本轮更新（2026-10-18）

本轮把这本书从“一本小册子”扩成一本人人都能读完的通俗读本（约 120 页）：

- **每一部加“三个小故事”**（看见／记住／跟上／选择／讲述／临界），故事在前、概念在后，四种读者各取所需；“动手试试”增至十余个。
- **新增五部**：十二个常见误解、给老师家长和孩子的一页、练习册二十道题、二十四个真实的人、三十个用法、一场三个人的谈话、一年之后的复盘、与五种批评对话。
- **插图**重绘并新增七张（划线、遗忘曲线、τ 赛跑、价目表、三个信号、一天六个核心、六个误解），全部由脚本确定性生成。
- **口径统一**：全书统一为“六个核心”，并同步六本专著与《热点的账单》。
