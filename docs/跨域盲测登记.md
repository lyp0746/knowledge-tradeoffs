## 一、登记规则

1. **时点**：登记日期为 2026-10-16；任何后续修订**不得改写**已登记行，只能在"新增"区追加新命题。
2. **信息边界**：登记所用的全部数值、阈值与数据来源，只能取自事件发生**之前**可得的公开信息。
3. **判定方式**：以**方向**而非点值判定（例如"置信区间是否发散"），避免量纲不可通约的问题。
4. **评分**：到预计完成年对照观测变量核对。**命中与落空都计入**，不因结果不利而删改。
5. **外部登记**：本文件即外部登记。任何读者可在 GitHub Issue 中引用编号并提出复核。

| E2 | 席位价不随执行单价下降 | 2028-10 前，**同一席位产品**（同条款）的公开最低价下降 **≤ 30%**；同期输出单价中位下降 **≥ 60%** | 两条方向同时成立 | 各家一手价目页 | 2028-10 |
| E3 | 溢价来自「没有替代品」而非「不可传递」 | 若某家把旗舰层权重开放（T 分升高），其溢价应在 **12 个月内收缩 ≥ 30%** | 观察到该情形且溢价未收缩，则本条被否证 | 权重发布记录 + 价目页 | 随事件 |

> E3 是「可传递性定价」假设的反向预言。第十四篇自己的 T8 已经否证了「溢价 ∝ 1／T」的简化版本；E3 换了一个更弱、可观测的方向：**不是 T 分高就便宜，而是 T 分在同一个模型上从低变高时，溢价要动**。若不动，说明溢价锁定在别处（品牌、评测、渠道），「不可传递性」这个解释就该整体放弃。

## 五、为什么这份登记很重要

一个诚实的框架，其价值不在于它说了多少正确的话，而在于它**敢不敢在事前说，并且接受失败**。

- 如果这些盲测**命中**，框架获得的不只是支持，而是**可被引用的、独立于作者的经验基础**。
- 如果它们**落空**，五本专著各自的可证伪登记簿将照实记录——**这比一百个成功案例更能让框架变科学。**
