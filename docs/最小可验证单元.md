## 二、逐条说明

### 1. 区分的语法 —— 杀手实验
- **复现**：`python analysis/graph_phase_transition.py`（见原书），Petersen 图 `(0.200, 0.500)`、环 `C₁₀ (0.250, 2.618)`。
- **杀手实验**：构造任意**正对称**边权，检验两个临界值是否总是 `β₁ ≤ β₂`。若找到一个反例，则"局部先于全局"不再是定理。
- **已知边界**：有向图（非对称）**可以**反转——这已被作者登记为反例（A 级），它不是杀手，而是边界。

### 2. 遗忘的边界 —— 杀手实验
- **复现**：信息瓶颈与率失真的标准推导。
- **杀手实验**：给定一个具体的记忆系统（生物或人工），若其遗忘曲线、干扰模式与巩固时间尺度**无法**被"有限容量 + 压缩 + 多尺度"同时解释，则"同约束"这一降级主张需要修改。
- **注意**：作者的防线是**拒绝同构论**——所以"三者机制不同"不构成反驳；反驳必须针对"受同一组约束"。

### 3. 错位的时间 —— 杀手实验
- **复现**：`τ = T_min/T_available`；三情景 τ≈0.5、3.5、30。
- **杀手实验**：在事前登记的场景里，找到一个 `τ≫1` 却仍被**精确预测**（而不是仅给方向）的案例。
- **配套**：作者已在原书第 11.7.1 节与附录 I 登记三个盲测（见 [`跨域盲测登记.md`](跨域盲测登记.md)）——请参与评分。

### 4. 选择的代价 —— 杀手实验
- **复现**：`python analysis/triangle_frontier.py`（n=12, K=15, 473721 种分配；`max C=0.58`、坐标和上界 ≈2.16）。
- **杀手实验**：找一个系统，三样都在满格，或三样都缺，却仍长期稳定——且无法用"鲁棒性"等第四性质解释。
- **最大风险**：三角的**万能化**（任何事都能事后说成"让出了某顶点"）。参见原书附录 T 的独立性检验协议。

### 5. 诠释的权衡 —— 杀手实验
- **复现**：把一场争论拆成四层并分配置信度（原书附录 A 的评分规则）。
- **杀手实验**：找到一场跨学科争论，双方在**事实层**就有系统性、无法用"分配位置"解释的分歧。
- **注意**：本书核心（置信度分配）不依赖前四本；即使四条"借用"全部失效，核心仍成立——这是它最该被检验的地方，也是它最稳的地方。
