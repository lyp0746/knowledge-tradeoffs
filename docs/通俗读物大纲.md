# 《只能选两样》通俗读物大纲

**副标题（候选）**：从来不及、会忘记到说不清——五个核心，看懂复杂世界的取舍
**英文**：*Pick Two — Five Ideas for Understanding a Complicated World*
**定位**：把五本专著的核心，写成一本人人都能读完、且读完后真的能用的小书。
**篇幅目标**：约 8–12 万字（首版先出 4–6 万字的完整骨架，逐章加密）。

---

## 一、一本书，四种读者：分层装置

全书每一节都同时提供四种深度，读者各取所需，互不打断：

| 装置 | 面向 | 形态 |
|---|---|---|
| **正文叙事** | 所有人（尤其小朋友） | 一家人的日常故事，零公式，每节一个小悬念 |
| **「多想一层」** | 学生 | 一个定义或公式 + 一句直觉解释 |
| **「再想一层」** | 成年人／从业者 | 证据等级（A/B/C）+ 边界 + 能带走的一个动作 |
| **「给专家的注」** | 专家学者 | 精确陈述、原始章节、反驳条件、失败记录 |
| **「动手试试」** | 全年龄 | 5 分钟能做完的小实验 |
| **「一句话带走」** | 所有人 | 章末一句 |

**人物设定（同时就是四种读者）**
- **小满**（10 岁）——读者里的小朋友，负责问出"为什么呀"。
- **姐姐**（大三）——读者里的学生，负责追问公式与证据。
- **爸爸**（工程师）、**妈妈**（医生）——成年人／从业者，负责"这跟我有什么关系"。
- **爷爷**（退休历史教师）——专家视角，负责"这个说法有多硬、哪里会错"。

> 约定：这一家人是**装置**，不是结论。他们只说普通人会说的话；凡涉及证据强度，一律交给分级装置，而不是让人觉得"作者在替某一派站台"。

## 二、全书结构

### 序章　三件小事，一个形状
- 急诊室的 30 分钟 / 妈妈的体检报告 / 爷爷的一桩"历史悬案"——三件毫不相干的事，形状相同。
- 引入全书比喻：**看得见的世界背后，都有一张看不见的账单。**
- "快、好、省，三选二"的游戏 → 预告"不可能三角"。
- 承诺：五个核心 = 五把读账单的钥匙；并说明**本书不承诺什么**（不预测、不万能、会被反驳）。

### 第一部　看见：一切从划一道线开始（对应《区分的语法》）
1. 小满分不清双胞胎——**区分是认识的第一步**。
2. "像不像"其实是一个数：相似性 = 二次型（用身高、口味、颜色举例）。
3. 系统的"性格"藏在谱里：琴弦泛音、鼓面、朋友圈（谱＝长期行为的方向）。
4. 局部先醒，还是全局先醒？——一场可复算的"两阶段相变"（森林火灾／传闻的比喻）。
5. 离散与连续之间有一道缝：**1/3 的缺口**（并警示：别把它当宇宙常数）。

### 第二部　记住：忘记是为了记住（对应《遗忘的边界》）
1. 书包只有那么大——**容量限制是前提，不是缺陷**。
2. 记住＝压缩：为什么"梗"比事实好记。
3. 遗忘其实是分级：工作记忆／短期／长期／终身——**容量级联**。
4. 睡一觉为什么有用：梦是"半夜的整理工"（明确标注：假说）。
5. 会忘的不只是人：大模型的位置偏差、智能体的目标漂移。
6. 边界：**同约束 ≠ 同构**——类比能照亮，不能证明。

### 第三部　跟上：不是不知道，是来不及（对应《错位的时间》）
1. 六个钟：金融（秒）／信息（分—时）／政治（周—月）／设施（年）／信任（年）／生态（十年—百年）。
2. τ = 需要的时间 ÷ 你有的时间（体检、台风、公司召回三个场景）。
3. 三种处境：来得及 / 勉强 / 来不及——**置信区间如何发散**。
4. 优雅降级：来不及的时候，先放弃什么。
5. 边界：τ 只做事后诊断与序数比较，**不做事前预测**。

### 第四部　选择：最贵的一句话是"我全都要"（对应《选择的代价》）
1. 三条腿的凳子：完备（C）／可组合（A）／传递（T）——用说明书、乐高、地图比喻。
2. 三张账单：
   - 要 C+A，让出 T → 1/3 缺口；
   - 要 C+T，让出 A → 子模性（**能力不能相加，1+1<2**）；
   - 要 A+T，让出 C → τ 发散。
3. 背包客的例子：为什么"带全、好收、一路通用"不能同时满足。
4. 知识的一生：大师（C+T）→ 教科书（A+T）→ 工厂（C+A）→ 革命（重回 C+T）。
5. 三角不是宿命，是价目表：**诊断 = 指出它让出了哪个顶点。**
6. 边界：为什么偏偏是"三"？（诚实登记为开放问题）

### 第五部　讲述：同一件事，为什么永远吵不完（对应《诠释的权衡》）
1. 爷爷的三句话：他说过 / 他因此被排挤 / 这标志一个时代——置信度从高到低。
2. 诠释 = 给竞争命题分配置信度（用"朋友圈断案"还原）。
3. 三种学者：清晰派 / 平衡派 / 细节派——各站三角的一个顶点。
4. 唐宋变革为什么吵了一百年：分歧多在**位置**，不在事实。
5. 用同一把尺子量自己：这套方法也可能失效，失败已登记。
6. 边界：诊断不等于判决，但诊断包含判断。

### 尾声　元学习：一本永远写不完的书
- 五个核心合成一句：**有限的世界只能靠取舍运转；看懂取舍，就看见了自己站在哪里。**
- 元学习闭环：观察 → 抽象 → 建模 → 应用 → 反馈 → 更新。
- 递邀请：这本书也可能错——告诉你它会怎么被反驳。
- 四条阅读路线（小朋友 / 学生 / 成年人 / 专家）。

## 三、写作纪律（沿用系列风格）

1. **张力，不宿命**：每条约束都要写出"它使什么成为可能"。禁止"必然／注定／无法消除"作为结论。
2. **分级在装置，不在每句**：正文一句一个精确限定即可，不反复免责、不表演式谦逊。
3. **反例进正文**，**失败照实写**：每个核心至少一个反例或一次失败。
4. **数字必有出处**：凡引用专著数字，标注原书章节与证据等级。
5. **每节一个悬念、一个故事、一个可带走的东西**。
6. **可玩**：每个核心至少一个 5 分钟小实验，小朋友能独立完成。
7. **不神化**：不把 1/2、1/3、2 说成宇宙规律；明确它们是标准数学的产物。
