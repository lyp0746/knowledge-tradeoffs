# 读者说明（《只能选两样》）

**这本书怎么读？** 四种读者，四条路线：

- **小朋友 / 陪读家长**：先读《零基础读法：连一个公式都不用看》，再读故事与「动手试试」。
- **学生**：加读「多想一层」；有兴趣可复算随书脚本。
- **成年人 / 从业者**：加读「再想一层」；用「时间错配 τ」「优雅降级」「三角诊断」三件工具。
- **专家学者**：读「给专家的注」，以及系列外部登记库 `docs/最小可验证单元.md`、`docs/跨域盲测登记.md`。

**发布包内容**：印刷版 PDF、电子阅读版 PDF、EPUB 3、网页版、Markdown、封面。
**不包含**：原始数据、脚本、源文件（见本仓库）。
