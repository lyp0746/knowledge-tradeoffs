# 《只能选两样》— 通俗读本

> 从来不及、会忘记到说不清——五个核心，看懂复杂世界的取舍

这本通俗读本把同一系列五本学术专著的核心，写成人人（从十岁到专家）都能读完的样子。

## 读者与用法

- **小朋友 / 陪读家长**：读故事与「动手试试」，跳过所有小框。
- **学生**：加读「多想一层」。
- **成年人 / 从业者**：加读「再想一层」。
- **专家学者**：读「给专家的注」，以及 [`../docs/最小可验证单元.md`](../docs/最小可验证单元.md)。

## 目录

- 序章　三件小事，一个形状
- 怎么读这本书：四种读者，四条路线
- 五个核心一页速查
- 第一部　看见（区分 / 二次型）
- 第二部　记住（容量 / 遗忘）
- 第三部　跟上（多尺度 / τ）
- 第四部　选择（C-A-T 不可能三角）
- 第五部　讲述（诠释＝置信度分配）
- 尾声　元学习
- 附录　关系图 · 术语 · 可验证单元 · 延伸阅读

## 构建

```bash
bash scripts/build.sh
# 书稿 Markdown -> HTML -> 插图/封面 -> 印刷PDF -> 电子PDF -> EPUB -> Markdown
```

产物在 `output/`：`book.pdf`（印刷版）、`book-ereader.pdf`、`book.epub`、`book.html`、`markdown/`。

书稿源在 `book-src/*.md`；正文 HTML 由 `analysis/md2book.py` 自动生成到 `source/`。
插图由 `analysis/make_figures.py` 生成（12 张矢量 SVG），封面由 `analysis/make_cover.py` 生成。
