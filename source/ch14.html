第14章　三十个用法：把它用在你自己的日子里

这一章是一张清单，不讲道理，只给做法。三十条，每条一句话，你随手挑三条用就够了。

14.1　看见（区分）：六条

  1. 听到一个标签，先问：“它把谁划在外面？”
  2. 想评价一个人，先把“他做了什么”和“他是什么人”分成两句话。
  3. 开会时，把“我们要服务谁”写下来，再看名单里少了谁。
  4. 整理房间，先决定“什么算同一类”，再动手——顺序反了会越整越乱。
  5. 看到“两个群体对比”的数据，先问这两类是怎么被划出来的。
  6. 当你觉得“这事说不清”，往往是因为你还没决定用哪条线切它。

14.2　记住（容量）：五条

  1. 睡前列三件“今天必须记住的事”，其余允许自己忘。
  2. 学新东西，先记结构（步骤、关系），再记细节。
  3. 复习安排在“快忘的时候”，而不是“刚学完的时候”。
  4. 给手机通知做一次减法：静音三个群，比装三个效率软件有用。
  5. 把“我记性差”换成“我的预算用完了”——这句话会让你去找方法，而不是自责。

14.3　跟上（时间）：五条

  1. 拖延的事，先算 τ，再决定“现在做”还是“改方案”。
  2. 给每件重要的事写“最晚开始时间”，而不是“截止时间”。
  3. 来不及的时候，先问“我先保住哪一样”，不要问“怎么全都保住”。
  4. 把“再观察一个月”改成“观察到什么信号就动手”。
  5. 和孩子、父母、同事约定事情，用“什么时候”而不是“尽快”。

14.4　选择（C-A-T）：五条

  1. 每次说“我全都要”，强迫自己划掉一个。
  2. 做决定时写下“谁为这个选择付代价”——写不出人名，说明你还没想清楚。
  3. 把“妥协”改叫“定价”：你不是在退让，你是在买。
  4. 团队里，把三个愿望写在白板上，让大家一起划——比争论谁对更快。
  5. 一年做一次“我们明确不做的事”清单，贴在看得见的地方。

14.5　讲述（诠释）：五条

  1. 生气时先说一句：“我们现在说的是事实，还是意义？”
  2. 把一句判断拆成事实、推理、诠释三行，各标一个置信度。
  3. 听到“专家说”，追问一句“他在哪一层说的”。
  4. 和立场相反的人讨论，先复述他的事实层，再谈意义层。
  5. 写重要的话时，把“肯定”换成“以现有材料看”——不是软弱，是准确。

14.6　临界：四条

  1. 每季度给自己一件事打三个勾（从无到有、越来越费力、宏观更好用）。
  2. 发现“越来越费力却越来越没效果”，先想“是不是该换目标”，而不是“再拼一点”。
  3. 对重要的系统（身体、关系、生意），留一条“提前降级”的方案。
  4. 判断“变天”之前，先分清“很重要”和“换了一个东西”。

14.7　五条“别这样用”

  1. 别用它评价人。 说“你这人就是容量不够”，等于把一张账单变成了判决。
  2. 别用它预测日期。 它能说“已经在变”，不能说“下个月塌”。
  3. 别把它当免罪符。 “反正只能选两样”是最偷懒的用法，它挡住了“那我到底要哪两样”。
  4. 别只在事后用。 事后解释人人都会；事前说一句可被推翻的话，才算用了它。
  5. 别指望它让你不难受。 它让你看清代价，而看清代价有时候更疼。

这一章的一句话：不必一次用三十条。挑一条，用一周；用得下去，再挑第二条。能被用起来的框架，才是活的框架。

一句话带走：能背下来的用法一定不够用，够用的用法一定背不下来。
