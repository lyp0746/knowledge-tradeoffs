## 五分钟读懂这个系列

### 一句话主张

> **看得见的世界背后，都有一张看不见的账单；这张账单只有三个价格——看得准、拼得上、传得下去，最多付得起两个。**

任何**有限复杂度**的知识系统，都不能同时完整地拥有三个性质：

- **完备性 C**（看得准）：每个部分都有自洽、可用、强到能预测的内部描述；
- **可组合性 A**（拼得上）：部分的组合不产生新的非线性项，能力可以叠加；
- **传递性 T**（传得下去）：不同尺度的结论可以无损互推。

**至多同时满足两个。** 让出哪一个，就留下哪一类可定位的账单。三角不是宿命，是一张**价目表**——诊断的核心动作，就是指出系统让出了哪一个顶点。

### 核心公式（三个可复算的硬核）

| 硬核 | 公式 | 等级 |
|---|---|---|
| 子模性（能力不能相加） | `I(Z; X₁∪X₂) ≤ I(Z; X₁) + I(Z; X₂)` | A／甲 |
| 图上两阶段相变 | `β₁ = α/λₙ`（局部先解锁）、`β₂ = α/λ₂`（全局后解锁） | A／甲 |
| 谱方差恒等式 | `κ_info(G) = Var(λ)/2` | A／甲 |
| 时间错配 | `τ = T_min / T_available`，可控性 `C = 1/τ` | A／甲（命题） |

## 这个仓库是什么

它把原本分散在五本专著里的**系列级材料**集中到一处，这正是审阅意见指出的最大缺口：

- [`docs/最小可验证单元.md`](docs/最小可验证单元.md) —— 每本书的 1 个 A 级硬核 + 1 个"杀手实验"（能证伪它的最小观测）。
- [`docs/跨域盲测登记.md`](docs/跨域盲测登记.md) —— **外部**、事前登记、允许失败的盲测；这是把"框架"变成"科学"的关键一步。
- [`docs/术语表.md`](docs/术语表.md) —— 五本书合并后的术语表。
- [`docs/五核关系图.svg`](docs/五核关系图.svg) —— 系列统一的关系图。
- [`docs/审阅与内在联系.md`](docs/审阅与内在联系.md) —— 对五本专著的逐本审阅与内在联系分析。

### 边界（本系列不做什么）

- **不**宣布大一统理论：三本书不是"同构"，而是"同约束"；区分语言不是"理论"，而是"语言"。
- **不**预测崩溃时点：τ 只做事后诊断与序数比较。
- **不**假装中立：诊断不等于判决，但诊断包含判断。
- **不**把 1/2、1/3、2 当宇宙常数：它们更可能是标准数学的产物。
