## 五分钟读懂这个系列

### 一句话主张

> **现实中没有无限。有限的承载者必须在描述、组合、传递之间分配同一份预算，于是那张账单只有三个价格——看得准、拼得上、传得下去，最多付得起两个。**

任何**现实的知识系统**，都不能同时完整地拥有三个性质：

- **完备性 C**（看得准）：每个部分都有自洽、可用、强到能预测的内部描述；
- **可组合性 A**（拼得上）：部分的组合不产生新的非线性项，能力可以叠加；
- **传递性 T**（传得下去）：不同尺度的结论可以无损互推。

**至多同时满足两个。** 让出哪一个，就留下哪一类可定位的账单。三角不是宿命，是一张**价目表**——诊断的核心动作，就是指出系统让出了哪一个顶点。

### 共同地基：有限性

这套书（九本书）有一个比任何公式都更靠下的前提：**现实中的每一个承载者都是有限的。** 无限只作为极限出现在模型里，从不出现在系统的实际状态里。有限性本身只说明“有上界”；它要变成“必须让出一个”，还需要三个条件同时成立：需求随规模增长、三种活动共享同一承载者、同时维持两种活动更贵（交互惩罚 ψ > 0）。**有限性是三角的必要前提，不是充分条件**——这正是三角被标为框架（C／丙）而不是定理的原因。每个卷首的《总纲　现实中不存在无限》把这条因果链写在最前面。

## 这个仓库是什么

它把原本分散在六本专著里的**系列级材料**集中到一处，这正是审阅意见指出的最大缺口：

- [`docs/系列速读.md`](docs/系列速读.md) —— 九本书，一人一页：一句话主张、最强证据、它承认的边界、怎么引用。
- [`docs/框架的四级与对话备忘录.md`](docs/框架的四级与对话备忘录.md) —— “框架”的四个强度，以及与 Kuhn／Lakatos／Latour／系统动力学的对话。

- [`docs/使用场景矩阵.md`](docs/使用场景矩阵.md) —— 每个工具在哪些场景能用、要改什么、已验证几例、什么场合别用。

- [`docs/术语表.md`](docs/术语表.md) —— 六本书合并后的术语表。

### 边界（本系列不做什么）

- **不**宣布大一统理论：三本书不是"同构"，而是"同约束"；区分语言不是"理论"，而是"语言"。
- **不**预测崩溃时点：τ 只做事后诊断与序数比较。
- **不**假装中立：诊断不等于判决，但诊断包含判断。
- **不**把 1/2、1/3、2 当宇宙常数：它们更可能是标准数学的产物。
